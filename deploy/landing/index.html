ModelLogue

状態遷移図・要求図・プロセス図などのモデルを、
人と AI の対話でレビューする。

アプリを開く → マニュアル

何をするツールか

テキスト → 正規モデル → 図＋表。AI と対話しながらモデルを磨き、レビューの経緯を資産として残します。

3 つのモデル型

状態遷移図・要求図・プロセス図。プラグイン構造で技法を追加できます。

AI と対話レビュー

図を「揮発するキャンバス」とし、人と AI の対話ログを設計の資産に。

マーカーと表

図に直接マーカーで指摘。遷移表・トレーサビリティ表・N-switch テストを自動生成。

ツールファミリー

同じ系統の、テスト設計技法のためのオープンなツール群（将来的に ModelLogue へ統合予定）。

ModelLogue 本体

モデルレビュー（状態遷移・要求・プロセス）。

アプリマニュアル

特徴

  • オープンソース（MIT） — 中身が見え、改造できる。
  • セルフホスト可能 — モデルを外部 SaaS に出さず自前で運用。
  • AI アシスト — 対話でモデルを磨く。
  • API・CLI から叩ける — 自動化・CI に組み込める。

API で試す（インストール不要）

デモ環境の公開 API に curl 一発。テスト設計をコマンドから。

# N-switch（状態遷移）テストを生成
curl -X POST 'https://modellogue.com/nswitch/generate' \
  -H 'Content-Type: application/json' \
  -d '{"source":"@startuml\n[*] --> A\nA --> B : go\nB --> [*] : done\n@enduml","n":1}'

# 組み合わせ（PICT / ペアワイズ）を生成
printf 'OS: Win, Mac, Linux\nBrowser: Chrome, Firefox\n' \
  | curl -X POST 'https://modellogue.com/pict/generate?order=2' --data-binary @-
